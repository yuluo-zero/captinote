# 麦克风指南：为什么它比换模型更重要

一句话结论：**这套工具准确率的天花板，是你收音的质量，不是模型。**

## 实测证据

同一套代码、同一个模型，两种录音：

| 音频 | 结果 |
|---|---|
| 干净近场（60 秒讲课） | `for a lot of times already, but we haven't actually had a class on it. So today we're going to do that in week six, lab two.` |
| 手机远场（5 米外教室） | `Next day you bring this truck...` / Parakeet 版：`Lastly, you read this trap...` |
| 老师真正说的 | 「明天把报告带来」 |

**两个模型都错了。** Whisper 和 Parakeet 在这个场景里互相 WER 高达 31.8%，不是模型差，是声音到麦克风时已经糊了。

## 远场为什么这么难

1. **距离衰减**：声压随距离平方衰减，5 米外的语音能量只剩 1/25
2. **混响**：教室墙壁反射，一个字的声音拖到下一个字上
3. **底噪**：空调、投影仪风扇、同学翻书
4. **口音叠加**：非母语发音本来就在模型分布边缘，再加混响更容易崩

## 怎么做

### 优先级 1：缩短距离

| 距离 | 相对效果 |
|---|---|
| 0.3–0.5 米（领夹麦） | 最好 |
| 1–2 米（桌面指向麦） | 可用 |
| 3 米以上（笔记本内置麦） | 明显下降 |

**坐前排**是最便宜的改善——不用买任何东西。

### 优先级 2：换指向性麦克风

| 类型 | 价格区间 | 适合 |
|---|---|---|
| **领夹麦（USB/无线） | 100–300 元 | 老师戴、或者你放在讲台边 |
| 指向性 USB 麦（如 Blue Yeti 类） | 300–800 元 | 桌面，对准声源 |
| 会议全向麦 | 500+ 元 | 小组讨论、多人说话 |

**别用笔记本内置麦**——它不是为远场设计的，实测在教室里几乎不可用。

### 优先级 3：老师用扩音设备时切成「系统声音」

如果教室有音响、老师戴无线麦讲话，声音会从电脑播放出来。
这时切换：

```
设置 → 音频来源 → 系统声音
```

直接抓电脑播放的音频，绕开物理距离，效果通常比麦克风好得多。

## 自检方法

1. **看界面**：录音中 6 秒没有有效声音，会红字提示「麦克风几乎没声音」
2. **看日志**：`logs/latest.log` 里有静音记录
3. **看音量条**：正常说话时应该有大半格高度

## 常见误解

| 误解 | 实际 |
|---|---|
| 「换个大模型就好了」 | 远场下所有模型都错，只是错的方式不同 |
| 「笔记本有降噪，应该够用」 | 系统降噪是为视频通话设计的，对远场语音识别帮助有限 |
| 「录音转写不行，实时肯定更差」 | 反过来才对——先录下来跑一遍，才知道到底是模型问题还是收音问题 |

## 一张决策图

```
听不清？
 ├─ 坐在后排 / 用内置麦 → 先坐前排，或买领夹麦
 ├─ 老师用音响扩音 → 切「系统声音」
 ├─ 安静环境还是错 → 检查术语表、换 Parakeet 试试
 └─ 以上都做了还错 → 那才是模型上限，这条路到头了
```
